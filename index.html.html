Caesar Cipher

شفّر نصك بإزاحة الحروف: كل حرف ينتقل عدداً ثابتاً من الأماكن، ونفس المفتاح يفكّه.

QR للناتج. اضغط مطولاً لحفظ الصورة أو صوّر الشاشة، ثم اقرأه بزر «قراءة QR».

تحليل Caesar

اكسر Caesar بدون مفتاح: يجرّب الموقع كل الاحتمالات ويرتّبها حسب الأرجح.

المفتاح النص بعد الفك الدرجة

يجرّب الموقع كل المفاتيح من 1 إلى 25 ويرتّب النتائج حسب شبهها بالإنكليزية (تحليل تكرار الحروف مع مكافأة للكلمات الإنكليزية الشائعة). السطر الأخضر هو الأرجح. النصوص القصيرة جداً قد تعطي ترتيباً غير دقيق، فراجع باقي النتائج.

Hash

بصمة ثابتة لأي نص (SHA-256 / SHA-512 / MD5)، أحادية الاتجاه ولا يمكن عكسها.

ملاحظة: الـ Hash لا ينفك (أحادي الاتجاه). تقدر فقط تقارن الناتج.

AES-GCM

تشفير حديث بمفتاح سري، ويكشف أي تعديل على الرسالة.

المفتاح السري نفسه يُستخدم للتشفير وفك التشفير. تقدر تكتب الـ Key والـ Nonce بنفسك، أو تضغط «عشوائي» لكل واحد منهما. الـ Key يبقى ثابتاً حتى تغيّره أنت، وتقدر تغيّر الـ Nonce مع نفس المفتاح. إذا تركت حقل الـ Nonce فارغاً يتولّد Nonce جديد مع كل تشفير. الـ Key يجب أن يبقى سرياً، أما الـ Nonce فليس سرياً لكن لا يجوز تكراره مع نفس المفتاح.

QR للمفتاح السري (منفصل عن QR الـ Ciphertext). شاركه بقناة مختلفة ولا تعرضه أمام الآخرين. اضغط مطولاً لحفظ الصورة.

QR يحتوي Nonce و Ciphertext فقط، بدون المفتاح. اكتب المفتاح بنفسك عند الفك (المفتاح لا يوضع بنفس الـ QR). اضغط مطولاً لحفظ الصورة.

كود Python الخاص بالمختبر (aes_lab4.py) 
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os

# 1) إنشاء المفتاح والـ Nonce
key = AESGCM.generate_key(bit_length=256)
nonce = os.urandom(12)

# 2) تشفير رسالة
message = "Hello Student!".encode("utf-8")
aes = AESGCM(key)
ciphertext = aes.encrypt(nonce, message, None)

print("Plaintext:", message.decode())
print("Ciphertext:", ciphertext.hex())

# 3) استرجاع النص الأصلي
recovered = aes.decrypt(nonce, ciphertext, None)
print("Recovered:", recovered.decode("utf-8"))
print("Match:", recovered == message)

RSA-OAEP

تشفير بمفتاحين: العام يشفّر والخاص يفك، فترسل رسالة سرية بدون ما تشارك مفتاحك الخاص.

بعكس AES (مفتاح واحد للتشفير والفك)، RSA يعتمد على زوج مفاتيح مرتبطين: الـ Public Key يُوزّع ويُستخدم لتشفير رسالة موجّهة لصاحب الزوج، والـ Private Key يبقى محمياً عند المالك ويُستخدم للفك. نستخدم هنا RSA-OAEP مع SHA-256 ومفتاح 2048 بت، وهو مناسب لرسائل صغيرة فقط.

أفضل الممارسات: استخدم OAEP (وليس PKCS#1 v1.5 أو RSA بدون Padding)، مع SHA-256 أو أقوى. المفتاح 2048 بت هو الحد الأدنى (≈112 بت أمان)، و 3072 بت للحماية الأطول (≈128 بت). الأس العام 65537، ولا تُشفَّر الملفات الكبيرة بـ RSA مباشرة بل بنظام هجين (AES + RSA). المفتاح الخاص هنا قابل للعرض لأغراض التعلم فقط، وفي الأنظمة الحقيقية لا يخرج من مكان حفظه.

عرض المفاتيح (PEM)

QR للـ Ciphertext فقط. لا نضع المفتاح الخاص بـ QR أبداً. الفك يحتاج نفس زوج المفاتيح الموجود بالصفحة.

كود Python الخاص بالمختبر (lab06_rsa_oaep.py) 
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.asymmetric import padding

# 1) إنشاء زوج المفاتيح
private_key = rsa.generate_private_key(
    public_exponent=65537, key_size=2048)
public_key = private_key.public_key()
print("Keys created")

# 2) إعداد OAEP (نستخدم نفس الدالة في التشفير والفك)
def oaep():
    return padding.OAEP(
        mgf=padding.MGF1(hashes.SHA256()),
        algorithm=hashes.SHA256(), label=None)

# 3) التشفير وفك التشفير
message = b"RSA lab message"
ciphertext = public_key.encrypt(message, oaep())
plaintext = private_key.decrypt(ciphertext, oaep())
print("Decrypted:", plaintext.decode())
print("Ciphertext bytes:", len(ciphertext))
